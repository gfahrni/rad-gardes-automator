RAD Gardes Automator V7 — version portable Windows
==================================================

Contenu
-------
RAD Gardes V7.exe   l'application (double-clic)
LISEZ-MOI.txt       ce fichier

Les trois documents d'exemple sont embarqués dans l'application : aucun
fichier à côté de l'exe.

Essayer en une minute
---------------------
1. Lancer « RAD Gardes V7.exe ».
2. Cliquer sur « Charger les exemples ».
3. Cliquer sur « Lancer ».
4. Le résultat s'affiche : 87/88, 3 rouges, 74 verts, 1 trou restant.
5. Les boutons ouvrent le planning rempli, le rapport ou le dossier.

Avec ses propres fichiers
-------------------------
Écran unique : choisir le PDF des gardes, le planning Excel et les souhaits
Excel, puis « Lancer ». Le dossier de sortie proposé par défaut est :
%USERPROFILE%\Documents\RAD Gardes Automator\run

Deux fichiers y sont écrits :
- planning-rempli.xlsx  le planning avec les gardes attribuées
- rapport.txt           le rapport complet

Aucune étape intermédiaire : l'application valide et calcule tout en une
fois. Si un fichier est incohérent, un message explique ce qu'il faut
corriger.

Version macOS
-------------
RAD-Gardes-V7-macos-arm64.zip est la version macOS (Apple Silicon) :
décompresser puis lancer « RAD Gardes V7.app ».

Rien à installer : Python n'est pas nécessaire.
